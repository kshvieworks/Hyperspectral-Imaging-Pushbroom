 |      This method is identical to calling capture(0).

 |  capture(...)
 |      capture(self: pecamerapy.include._pecamerapy.Camera, frames: int, pythonBufferSize: int) -> None
 |      
 |      Captures a finite number of frames or start/stop continuous capture. The value of the `frames` parameter defines the number of frames that will be acquired by the camera.The value of the `pythonBufferSize` parameter defines the size of the circular buffer that stores the frames produced by the underlying c++ layer. A large buffer ensures that no frame are lost. Keep in mind that this circular buffer is different from the frame grabber buffer. It is possible to abort a frame while the camera is exposing, but not while it is transferring the frame.A frame aborted during the exposure will not be transferred and therefore will not be added in the buffer.
 |  
 |  capture_video(...)
 |      capture_video(self: pecamerapy.include._pecamerapy.Camera, pythonBufferSize: int) -> None
 |      
 |      Captures a continuous stream of frames. The frames are taken as fast as the camera can output them. The value of the `pythonBufferSize` parameter defines the size of the circular buffer that stores the frames produced by the underlying c++ layer. A large buffer ensures that no frame are lost. Keep in mind that this circular buffer is different from the frame grabber buffer.

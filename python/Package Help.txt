Help on package pecamerapy:
NAME
    pecamerapy
DESCRIPTION
    Python API for PeCamera
    Usage:
        Create a Camera() handler and then use method on said object. First open a camera on this handler before any other method.
        
        ex:
    
            camera = pecamerapy.Camera() # equivalent to PEC_CREATE()
    
            camera.open(0, OpenMode.USB3)
    
        The signature of every method can be deduced from the c++ methods of `Zephir - SDK User Manual`.
        To work with PeCameraPy methods, note that:
    
            - Every Python method use the snake_case convention instead of CamelCase.
            - Error code are not returned but instead thrown as Exception.
            - In-place arguments are returned as tuple instead (as many Python object are immutable) or as a single argument
            if there's only one argument.
            - 'size' arguments that specify length of strings are not used anymore.
            - Callback are not currently available. One must use `capture` and `get_image` to capture images.
            - `capture` and `captureVideo` have a new `pythonBufferSize` argument which controls a circular buffer
            that accumulates the images of the c++ sdk.
    
        ex:
    
            c++'s findFirst method:
    
                `int res = pec->findFirst(PeCamera::OpenMode mode, int* index, char* serial, int size)`
            
            becomes python's find_first method:
    
            try:
    
                index, serial =  camera.find_first(PeCamera.OpenMode.USB3)
    
            except Exception as e:
    
                print(f"error while connecting: {e}")
    
        ex:
    
            camera.find_first() will return (index, serial).
    
            camera.get_metadata_enabled() will return a bool.
